# @kindling/assets

The asset pipeline as reusable tools: a fal.ai client with cost logging and wrappers for the models we used (Nano
Banana image sheets, Tripo image-to-3D, ElevenLabs sound effects), prompt files as data, sheet slicing with clean
keying and contact sheets, headless Blender modules (procedural textures and CPU bakes, sockets, GLB export,
thumbnails, rig transfer, a GLB verifier), a licence / attribution registry, a browser screenshot harness, and the
reinforcement-learning bridge (env server helper, PPO trainer template, JSON policy runtime). Node-only, except
`@kindling/assets/policy`, which is browser-safe.

## Why

See [docs/LESSONS.md](../../docs/LESSONS.md):

- **Asset pipeline**: assets are generated by scripts and never hand-edited, so they are reproducible. Batch many
  icons into one sheet on a flat chroma background, slice and key them; log every call and its cost; keep prompts in
  files; keep raw outputs so slicing can be re-run. Check every downloaded asset's licence and record attribution.
- **Rendering**: never run GPU compute on the machine driving the desktop. Every Blender module forces Cycles onto
  the CPU (or uses Workbench); the trainer is CPU torch.
- **Balance and testing**: verify visuals with real browser screenshots at several resolutions and look at them;
  an RL agent over a stdin/stdout env found real strategies the scripted bot lacked.

## API (node)

| Module           | Exports                                                                                                                                                                                                                                                                                                                        |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `fal.ts`         | `FalClient({ key, logFile, fetch, sleep, pollMs, timeoutMs, costs, log })`: `run(model, input, label)` (submit, poll, result, one calls.log line with model, label, estimated $, request id, ms), `download`, `estimate`; `loadEnv(dir)` (.env, searched upward), `FAL_COSTS`, `readCallLog`, `asUrl` (local file -> data URI) |
| `models.ts`      | `nanoBanana(fal, { prompt, images?, aspect, resolution, seed, tier })` (edit endpoint when given reference images), `tripoImageTo3d(fal, { image, faces, texture, seed })`, `elevenSfx(fal, { text, seconds })`, `saveOutputs` (downloads + `<name>.meta.json` with the exact input)                                           |
| `prompts.ts`     | `PromptFile` (style, itemStyle, suffix, background, tier, aspect, resolution, seed, cols, references, items, sheets), `loadPromptFile`, `validatePromptFile`, `sheetPrompt`, `itemPrompt`, `sheetLayout`, `sheetAspect`                                                                                                        |
| `sheets.ts`      | `generateSheet(fal, file, name, dir)` (raw PNG + layout JSON + meta; skips existing), `sliceSheet(opts)`, `contactSheet(opts)` (both run `python/sheets.py`)                                                                                                                                                                   |
| `credits.ts`     | `CreditsFile` (`assets.credits.json`: roots, ignore, entries), `validateCredits(file, base, { publicBuild })`, `formatAttribution`, `LICENCES`, `globToRegExp`                                                                                                                                                                 |
| `screenshot.ts`  | `screenshots({ targets, out, sizes, waitFor, settleMs, chromium, ignore })` -> `{ files, problems }` (console errors, page errors, failed requests, timeouts per shot); `DEFAULT_SIZES`, `findChromium`                                                                                                                        |
| `rl/protocol.ts` | `serveEnv(spec, make, { nenv, seed, io })`, `RlEnv` (`reset(seed)`, `observe(out, offset)`, `step(actions) -> { reward, done, result }`), `EnvSpec` (`obs`, `heads`, `meta`)                                                                                                                                                   |
| `rl/client.ts`   | `EnvClient(cmd, args, env)`: spawns a server, reads its INFO spec, `reset()`, `step(actions)`, `close()`                                                                                                                                                                                                                       |
| `rl/policy.ts`   | `Policy(json)`: `forward(obs)` (logits per head), `act(obs, rand?)`; `argmax`, `softmax`, `sample`                                                                                                                                                                                                                             |

Protocol (little-endian, unframed): server writes `obs[NENV*OBS] f32`; then per step reads `act[NENV*HEADS] i32`
and writes `obs[NENV*OBS] f32` + `reward[NENV], done[NENV], result[NENV] f32`; an env that finishes is reset by the
server. `INFO=1` prints `{"obs", "heads", "nenv", ...meta}` and exits.

## CLIs

```sh
kindling-sheet prompt prompts.json fire              # print the sheet prompt (no call)
kindling-sheet gen prompts.json raw/ [sheet...]      # generate raw sheets (spends credit; raw/calls.log)
kindling-sheet cut prompts.json raw/ icons/ --size 96 --quantize 5 --alpha hard --tile '#968a6e'
kindling-sheet cost raw/                             # spend so far
kindling-credits validate assets.credits.json [--public]
kindling-credits attribution assets.credits.json > CREDITS.md
kindling-shots http://localhost:5173/?bots=1 --sizes 1920x1080,1280x720,1440x900 --wait "window.game?.ready" --contact shots/contact.png
```

Templates: `templates/icons.prompts.json`, `templates/assets.credits.json`.

## Python and Blender

- `python/sheets.py` (numpy + Pillow): `slice` finds cells from the background gaps (equal grid fallback), keys the
  background with a soft edge, unmixes the anti-aliased fringe in a band along the background (no pink halos) and
  despills the rest, trims, pads square, resizes with premultiplied alpha, optionally quantises / hardens alpha and
  composites on a consistent frame tile. `contact` draws labelled thumbnails in a grid.
- `blender/kindling_bpy/` (run with `nice blender -b --factory-startup -P script.py -- args`):
  `scene` (reset, `cycles_cpu`, `workbench`), `texgen` (seeded tileable noise / bricks / planks / cobbles, N64
  palette reduction, `to_image`), `bake` (`Graph` node DSL, `bake_procedural` CPU emission bake to an image,
  `flat_material`, `textured_material`, `unwrap`), `sockets` (`socket(name, parent, loc, rot, **extras)`, `tree`),
  `export` (`export_glb(objs, path, animations=False)`), `thumbs` (`import_glb`, `render_thumb`), `rig`
  (`transfer(mesh_glb, rig_glb, out_glb, yaw, height, decimate)` and its steps), `verify` (plain Python GLB checks:
  nodes, materials, triangle budget, ground contact, extras, clips, skin; also a CLI).
- `blender/smoke.py`: the test's smoke run; `blender/demo_parts.py`: the @kindling/three demo's part GLBs.
- `rl/train.py` (CPU torch PPO, `ENV_CMD="node ... env.ts" RUN=runs/x python3 rl/train.py`, `BASELINE=1` for the
  scripted bot's own win rate) and `rl/export.py <ckpt.pt> <out.json>` for the TS runtime.

## Usage

```ts
import { FalClient, loadEnv, loadPromptFile, generateSheet, sliceSheet } from "@kindling/assets";

loadEnv();
const fal = new FalClient({ logFile: "assets/generated/icons/calls.log", log: console.log });
const prompts = loadPromptFile("tools/icons.prompts.json");
await generateSheet(fal, prompts, "fire", "assets/generated/icons");
sliceSheet({
  sheet: "assets/generated/icons/sheet_fire.png",
  meta: "assets/generated/icons/sheet_fire.json",
  out: "assets/ui/icons",
  size: 96,
  quantize: 5,
  alpha: "hard",
});
```

An RL env for a game (the game supplies the env; share `observe` with the in-game agent):

```ts
import { serveEnv } from "@kindling/assets/rl";
await serveEnv({ obs: OBS, heads: [10, 8] }, () => new MyGameEnv()); // INFO=1 prints the spec
```

## Tests

`pnpm test` (no network, no credit): fal client against a mocked fetch (submit, poll, result, calls.log, errors,
.env), prompt files, slicing a synthetic magenta sheet (cells in order, clean keyed edges, quantise / hard alpha,
contact sheet), credits validation, the env protocol round trip with a toy env over stdin/stdout, the policy
forward pass against a hand-computed network, the screenshot harness on a data: page, and one Blender smoke run
(textured part with sockets and a CPU bake, thumbnail, rig transfer, all verified). `SKIP_BLENDER=1` skips the
Blender run.

## In Grudge

`fal.ts` / `models.ts` replace the `falRun` copies in `tools/gen-asset.mjs`, `gen-hero-sheet.mjs`,
`gen-talent-icons.mjs`, `gen-campaign-icons.mjs` and `gen-sfx.mjs`; `python/sheets.py` is
`tools/campaign-icons-cut.py` and `slice-talent-sheets.py`; the Blender modules come from `tools/blender/texgen.py`,
`build_tripo_hero.py`, `build_tripo_unit.py` and RUST RING's `tools/blender/kit.py`, `render_thumbs.py` and
`verify_assets.py`; the RL bridge is `tools/ml/env.ts`, `train.py`, `export.py` and `src/sim/bot/agent.ts`;
`screenshot.ts` the many throwaway playwright scripts.
